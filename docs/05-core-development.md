## 2. 已验证边界

- 1、20、60 分钟开始与显示取整；
- 0／1 秒提前结束边界；
- 暂停、继续和确认期间不累计有效时长；
- 非法 reducer 事件与陈旧会话 ID 被忽略；
- 自然完成和提前结束共用同一结算入口；
- 重复结算返回同一回执且日汇总只增加一次；
- 自然／提前结算竞争只产生一次汇总增量；
- 注入失败时，日汇总、回执、活动会话删除和最后完成引用整体回滚；
- 本地日期跨月、跨年，15 天补零、7 天求和和全零基线；
- 损坏的活动会话、日汇总和运行时字段按对象或字段隔离。
