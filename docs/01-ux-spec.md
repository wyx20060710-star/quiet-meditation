# 极简冥想计时器：低保真与完整交互规格

> 阶段：1 — 低保真与交互  
> 版本：1.0  
> 日期：2026-08-04  
> 上位约束：`PROJECT_CHARTER.md`  
> 适用对象：产品、视觉设计、动效设计、前端开发、测试

## 1. 文档目标与边界

本文定义三个主要页面在电脑与手机上的低保真结构、状态、交互、响应式行为和验收条件。它描述用户应看到什么、操作后发生什么，以及异常恢复后的预期结果；不指定前端框架、依赖、存储实现或正式视觉参数。

本阶段只包含：

- 首页；
- 冥想进行页；
- 完成页；
- 附着在上述页面上的临时控制、确认层和展开区。

本阶段不包含第四个主要页面、账号、云同步、课程、社交、游戏化、推送、复杂设置或长期分析，也不创建前端工程和业务代码。

## 2. 核心体验原则

1. 首页打开后，用户无需阅读说明即可在默认 20 分钟下开始。
2. 进行页默认只有圆环和剩余时间，操作控件按需出现。
3. 计时主体在控制显隐、暂停和确认过程中保持固定位置。
4. 所有完成都得到明确但克制的结果反馈；自然完成与提前结束均只结算一次。
5. 记录是次级信息，首页仅给摘要，15 天趋势只在完成页由用户主动展开。
6. 主题和声音是次级偏好，不进入进行页。
7. 页面刷新、切后台、锁屏、关闭重开不会让用户面对漂移、负数、重复结算或重复完成音。

## 3. 术语与统一显示规则

| 术语 | 定义 |
|---|---|
| 计划时长 | 用户在首页选择的 1～60 分钟整数；默认 20 分钟 |
| 实际时长 | 从开始到结束的有效冥想秒数，不含暂停时间 |
| 自然完成 | 有效剩余时间到 0 |
| 提前结束 | 用户在确认后主动结束，实际时长可以小于计划时长 |
| 今日 | 设备当前本地自然日 |
| 最近 7 天 | 含今日在内连续 7 个本地自然日 |
| 最近 15 天 | 含今日在内连续 15 个本地自然日；缺失日期按 0 展示 |
| 一次完成 | 自然完成或经确认的提前结束；同一会话只计一次 |

统一时间格式：

- 首页选择值使用“20 分钟”；
- 进行页剩余时间使用 `MM:SS`，1～9 分钟补为 `01:00`，60 分钟显示 `60:00`；
- 完成页本次时长和统计：整分钟显示“20 分钟”，不足或多出的秒数显示“3 分 24 秒”；0 秒不形成完成记录；
- 首页摘要以分钟为主；不足 1 分钟但大于 0 秒时显示“少于 1 分钟”，避免误显示为 0；
- 日期标签优先使用“今天”“昨天”，其余使用 `M/D`；
- 所有时长在内部以秒为准，界面文案不得反向成为计算依据。

## 4. 全局信息架构与主流程

```text
首页（准备）
  ├─ 选择时长／主题／声音
  └─ 开始 → 进行页（进行中）
                 ├─ 点空白 → 控制显现 ─ 无操作 → 控制隐藏
                 ├─ 暂停 → 进行页（已暂停） ─ 继续 → 进行中
                 ├─ 提前结束 → 确认层
                 │              ├─ 继续冥想 → 返回此前状态
                 │              └─ 确认结束 → 完成页（提前结束）
                 └─ 剩余归零 → 完成页（自然完成）

完成页
  ├─ 查看最近记录 → 原页渐进展开／收起
  ├─ 返回首页 → 首页（保留上次计划时长）
  └─ 再次冥想 → 以本次计划时长直接开始新会话
```

“再次冥想”采用直接开始，理由是按钮文案已明确表达动作，并能缩短重复冥想路径。它复用上一会话的计划时长，而不是提前结束时的实际时长。用户若要更改时长，应选择“返回首页”。

## 5. 全局布局基线

这些是阶段 1 的结构关系，不是最终视觉设计值。

### 5.1 断点与页面容器

| 范围 | 结构规则 |
|---|---|
| 手机：320～767 px | 单列；左右安全边距至少 20 px；主要按钮接近全宽；兼顾系统安全区 |
| 平板／窄桌面：768～1023 px | 仍以单列居中为主；内容宽度受限，增加外侧留白 |
| 桌面：≥1024 px | 单列居中；核心任务区建议最大宽度 560～640 px；次级信息不横向扩张成仪表盘 |

页面应支持至少 320 px 宽度和 200% 文字缩放。使用动态视口高度时，核心按钮和进行页控制不得被浏览器工具栏或安全区遮挡。

### 5.2 尺寸关系

- 页面内容区顶部、主体、底部之间使用明显层级留白；
- 首页当前时长是最大文字，标题次之，统计和偏好控制最弱；
- 进行页圆环直径：手机约为可用宽度的 68%～78%，桌面约为可用高度的 42%～52%，同时受最大尺寸约束；
- 圆环和时间组成一个不可位移的固定主体盒；
- 所有可点击／触控目标最小 44 × 44 px；
- 快捷值之间保持可区分间距，320 px 下也不得重叠；
- 完成页首屏先容纳结果与两个核心去向；趋势展开后允许页面纵向滚动。

### 5.3 焦点、键盘与读屏顺序

- 焦点样式必须清晰，不只依靠颜色；
- `Tab` 顺序与视觉顺序一致；
- `Enter`／`Space` 激活按钮；方向键调整滑块，步长 1 分钟；
- 页面进入新主状态时，将焦点放到页面标题或状态摘要；确认层打开时焦点进入确认层，关闭后回到触发按钮；
- 状态变化通过简短的礼貌级实时区域播报，不每秒播报倒计时；
- 进行页的剩余时间应有可访问名称，例如“剩余 19 分 42 秒”，视觉仍显示 `19:42`。

1. 页面标题“冥想”；
2. 当前选择时长；
3. 快捷时间；
4. 1～60 分钟滑块；
5. “开始冥想”主按钮；
6. 今日与最近 7 天摘要；
7. 主题与完成提示音控制。

- 视口高度不足时允许整页滚动，不缩小触控目标或压扁间距。

```text
│ 最近 7 天 0 分钟           │

```

手机规则：

- 次级偏好可同行紧凑排列；若 320 px 或文字放大后空间不足，允许换为两行，但不得覆盖标题；
- 五个快捷时间保持一行；必要时缩短横向内边距，不缩小可触控区域，可用按钮容器的间隙承接触控面积；
- 主按钮为内容区全宽；
- 统计可分两行，顺序固定为今日、最近 7 天。

### 6.4 选择时长交互

初始状态：

- 首次打开选中 20 分钟；
- 从完成页返回首页时保留上一会话的计划时长；
- 普通刷新保留当前已选择但尚未开始的时长；若数据无效则回到 20 分钟。

快捷时间：

- 点击 5、10、15、20、30 中任一值，立即更新大号时长与滑块；
- 选中态同时使用形状／边框或明确的 `aria-pressed` 状态，不只改变颜色；
- 每次只能有一个快捷值处于选中态。

滑块：

- 范围 1～60，步长 1 分钟；拖动、点击轨道或键盘调整时，大号时长即时更新；
- 当值等于快捷值时，对应快捷按钮同步选中；其他值下五个快捷按钮均不选中；
- 滑块当前值必须有可读标签；视觉上可在滑块下方显示当前整数，不能与拇指重叠；
- 调整过程中不触发开始，也不产生声音或强动效。

开始：

- 点击“开始冥想”立即建立新会话并进入进行页；
- 防止双击或连续按键创建两个会话；第一次有效激活后按钮不再响应重复开始；
- 新会话的计划时长取按钮激活瞬间的选择值。

### 6.5 主题与声音

- 主题控制在“自然矿石／柔和晨雾”之间切换，选择立即生效并本地记忆；
- 控件必须有文本或明确可访问名称，不只用无标签图标；
- 声音为“完成提示音：开／关”，默认开，选择本地记忆；
- 声音开关不在点击时播放测试音；
- 两项控制不打开独立设置页，不阻断开始路径。

### 6.6 首页统计状态

| 数据状态 | 今日摘要 | 最近 7 天摘要 | 行为 |
|---|---|---|---|
| 空记录 | 今天 0 分钟 | 最近 7 天 0 分钟 | 正常显示，不用空状态插画或引导 |
| 仅今日 1 条 | 显示今日累计 | 与今日相同 | 同一条记录不得被重复相加 |
| 近 7 天多条 | 显示今日累计 | 显示 7 天总计 | 不展示图表或排名 |
| 只有 8～15 天前记录 | 今天 0 分钟 | 最近 7 天 0 分钟 | 旧记录只在完成页 15 天趋势中出现 |
| 数据损坏／不可读 | 今天 0 分钟 | 最近 7 天 0 分钟 | 静默回到安全空记录；页面仍可开始 |

## 7. 冥想进行页

### 7.1 稳定构图

进行页始终保留三个固定层：

1. 全屏交互背景层；
2. 居中的圆环与时间主体层；
3. 预留在固定位置的控制层／确认层。

控制层的显隐使用透明度和可交互性变化，不新增文档流高度，因此圆环和时间不得位移。页面不显示标题、统计、主题、声音、菜单、说明、阶段文案或呼吸指令。

### 7.4 状态规格

#### A. 进行中／控制隐藏

- 圆环连续表达剩余比例，时间每秒显示当前剩余整秒；
- 轻微呼吸效果运行，但不改变进度真值；
- 点击或轻触不属于按钮的空白区域，显示控制；
- 键盘用户按 `Tab` 或 `Space` 可显示控制，`Escape` 在控制可见时隐藏控制；
- 点击圆环本身视为空白区域交互，但点击时间文本不选择文字；
- 页面不得因鼠标移动而频繁显隐，桌面可把首次有意点击／键盘操作作为明确唤出动作。

#### B. 进行中／控制显现

- 显示“暂停”和“提前结束”；
- 控制出现后开始无操作计时，建议 4 秒后淡出；任何指针、触控或键盘操作重置计时；
- 点空白区域可立即隐藏；
- 鼠标悬停、键盘焦点位于控制上或确认层存在时不得自动隐藏；
- 自动隐藏只改变控件可见性，不改变计时状态；
- 控件淡出后不可被误点，也不得保留在 `Tab` 顺序中。

#### C. 已暂停

- 点击“暂停”后立即冻结有效剩余时间、进度与呼吸；
- 时间不继续减少，清晰显示状态文本“已暂停”；
- “继续”保持可见且为主操作，“提前结束”为次操作；
- 暂停态控件不自动隐藏；点击空白不能隐藏“继续”；
- 页面切后台或刷新后恢复仍为暂停，不自动继续；
- 点击“继续”后恢复进行中，状态播报“计时已继续”，控制可短暂保留后按 4 秒规则隐藏。

暂停线框：

```text
┌────────────────────────────┐
│                            │
│        ╭──────────╮        │
│       │    12:08    │       │
│        ╰──────────╯        │
│          已暂停            │
│                            │
│ [   继续   ] [ 提前结束 ]  │
│                            │
└────────────────────────────┘
```

#### D. 提前结束确认

- 从进行中或暂停态点击“提前结束”，打开原页内的简短模态确认层；
- 确认层出现瞬间冻结计时，避免用户阅读确认时被计入实际时长；
- 文案：“结束本次冥想？”；补充：“将记录已经冥想的时间。”；
- 操作：“继续冥想”（主）和“结束并记录”（次／谨慎操作）；
- 从进行中打开后，选择“继续冥想”恢复计时；从暂停态打开后，选择该项回到暂停态，不自动继续；
- 点击遮罩或按 `Escape` 等同取消，回到此前状态；
- 确认层不使用危险红色作为唯一警示，不出现“失败”“放弃”等施压词。

```text
┌────────────────────────────┐
│       （背景弱化）         │
│    ┌──────────────────┐    │
│    │ 结束本次冥想？   │    │
│    │ 将记录已经冥想   │    │
│    │ 的时间。         │    │
│    │                  │    │
│    │ [继续冥想]       │    │
│    │ [结束并记录]     │    │
│    └──────────────────┘    │
└────────────────────────────┘
```

若实际有效时长仍为 0 秒，确认文案改为“尚未产生可记录的时长”，确认操作为“结束并返回”；确认后不新增记录，返回首页。这避免制造 0 秒完成记录。

#### E. 自然完成

- 剩余时间首次到 0 时立即停止进度与呼吸，显示 `00:00`；
- 原子地完成一次结算，然后进入完成页；
- 完成提示音仅在偏好开启、页面当时活跃且音频可播放时尝试一次；
- 音频失败不显示阻断弹窗，不延迟页面转换；
- 快速连续回调、刷新或恢复不得再次结算或再次播放。

#### F. 提前结束

- 点击“结束并记录”后，以确认层冻结时已经累积的有效时长结算一次；
- 不播放完整完成音；
- 进入同一个完成页结构，但使用提前结束的中性结果文案；
- 本次计划时长仍被保留，供“再次冥想”使用。

### 7.5 返回、刷新与恢复

| 场景 | 预期行为 |
|---|---|
| 浏览器后退／PWA 系统返回，进行中 | 不静默丢弃会话；打开与“提前结束”相同的确认层 |
| 刷新，截止时间未到 | 回到进行页，按真实经过时间恢复剩余时间 |
| 刷新，原状态为暂停 | 回到暂停态，剩余时间保持刷新前的冻结值 |
| 后台／锁屏后在截止前恢复 | 立即按真实时间差校正显示，不播放补偿动画 |
| 后台／锁屏期间已经到期 | 只结算一次并进入完成页；仅在应用当时具备活跃播放条件时才尝试完成音，不因晚到恢复而重复播放 |
| 关闭后在截止前重开 | 恢复同一会话，不新建、不重置 |
| 关闭后在截止后重开 | 安全结算一次并显示完成页；不补播完成音 |
| 恢复数据不完整／损坏 | 放弃不可证明有效的活动会话，回到首页；不创建猜测性记录 |
| 系统时间明显变化 | 不显示负数；尽可能维持已累积有效时长与单次结算，无法可信恢复时按损坏会话规则回首页 |

恢复过程允许出现极短的中性加载占位，但不得先闪现错误剩余时间或首页再跳回进行页。

### 8.4 完成页操作

- “再次冥想”为主要操作：以刚结束会话的计划时长直接创建新会话并进入进行页；需防重复激活；
- “返回首页”为次操作：返回首页并保留计划时长；统计已更新；
- “查看最近记录”为渐进展开按钮，使用原页纵向展开，不进入新页面；
- 展开后按钮改为“收起最近记录”，`aria-expanded` 同步；
- 展开时焦点仍留在展开按钮，内容紧随其后进入阅读顺序；
- 收起后移除隐藏内容的焦点能力；
- 浏览器后退：若由首页完成流程进入，返回首页，不回到已结束的进行页；不得重复结算。

### 8.5 最近记录内容与数据状态

展开区固定顺序：

1. 最近 7 天总时长；
2. 最近 7 天完成总次数；
3. 最近 15 天小型柱状趋势；
4. 今日时长与次数的轻量摘要。

柱状图规则：

- 固定展示含今日的 15 个自然日，缺失日为 0 高度；
- 所有柱使用同一量纲，以 15 天内最大日时长为相对满高；全为 0 时显示基线；
- 至少标注首日、昨天、今天，避免 15 个完整日期在手机上拥挤；
- 每根柱有可访问文本，例如“8 月 4 日，35 分钟，2 次”；
- 0 值仍保留日期语义和最小基线标记，不伪造正数高度；
- 图表不表达目标、好坏、连续天数或排名。

| 数据状态 | 展开区表现 |
|---|---|
| 空记录 | 正常情况下完成页不会为空；若记录读取失败，显示“最近 7 天 0 分钟”“暂无可显示的最近记录”，趋势为 15 天零基线 |
| 仅今日单次 | 7 天总计等于本次；趋势仅今天有柱；显示“今天 … · 1 次” |
| 单日多次 | 今日柱为当日累计；次数显示合计，不画多根会话柱 |
| 2～14 个有记录日期 | 无记录日期补零，时间轴仍连续 |
| 完整 15 天 | 展示 15 根日汇总柱；不出现横向滚动或第 16 天 |
| 超过 15 天的本地旧数据 | 不展示且应在数据层清理；界面不提示“历史丢失” |
| 数据异常 | 展开区安全退为空状态，不影响返回首页或再次冥想 |

## 10. 自动隐藏与输入冲突规则

- 自动隐藏只适用于“进行中且控制显现”；暂停和确认状态永不自动隐藏关键操作；
- 自动隐藏倒计时建议 4 秒，阶段 3 可在不改变行为语义的前提下微调；
- 指针按下按钮后即使控件达到隐藏时刻，也应完成这次明确操作；
- 多点触控只接受第一个有效按钮激活，不能同时暂停和结束；
- 快速双击“暂停”不得立即暂停又继续；“继续”按钮在状态更新完成前只接受一次；
- 页面失去焦点时，正在打开的结束确认保持冻结；恢复后仍等待用户选择；
- 触摸滚动完成页展开区不得误触“再次冥想”或“返回首页”。

## 11. 响应式与极端尺寸

### 11.1 横竖屏

- 手机竖屏为主要构图；
- 手机横屏或低高度桌面中，圆环按可用高度缩小，控制区可移到圆环右侧，但时间仍在圆环中心，信息顺序不变；
- 横竖屏切换不得重置、暂停、继续或重复结算；
- 旋转过程中若确认层已打开，确认层保持打开且焦点不丢失。

### 11.2 文字放大与内容溢出

- 200% 文字缩放时允许页面纵向滚动；
- 快捷时间若无法安全维持一行，可使用等宽紧凑网格换行，但顺序不变；
- 按钮文案不得截断为省略号；
- 进行页 `MM:SS` 不换行；圆环可缩小给状态文字和控制留空间；
- 完成页图表宽度跟随容器，不横向滚动。

### 11.3 安全区与浏览器界面

- 手机底部按钮距安全区至少保持可触控间距；
- 浏览器地址栏收起／展开不引发圆环明显跳动；
- 虚拟键盘通常不参与核心流程；键盘导航造成视口变化时，聚焦按钮仍需可见。

## 12. 减少动态效果

当系统声明减少动态效果时：

- 取消圆环的呼吸缩放，仅保留静态尺寸和进度变化；
- 控件与页面可直接出现／消失，或采用极短淡变；
- 展开区直接展开，不使用高度弹性动画；
- 不改变自动隐藏时机、状态转换或计时精度；
- 不需要单独设置入口，跟随系统偏好即可。

## 13. 错误与降级表现

| 异常 | 用户可见结果 |
|---|---|
| 本地记录缺失／损坏 | 页面正常打开，统计按空记录显示；不弹侵入式错误 |
| 活动会话损坏 | 回首页，不结算猜测时长；选择与偏好能验证则保留 |
| 完成音失败 | 完成页照常出现，不弹错误；同次会话不反复重试 |
| 本地偏好不可保存 | 本次页面内选择仍生效；下次可能回默认，不阻断使用 |
| 离线 | 核心三页、计时和本地记录正常可用；不显示持续离线警告 |
| PWA 不可安装／安装失败 | 普通网页完整可用；核心流程不出现安装失败提示 |
| 图表数据局部异常 | 忽略无效日并按 0 展示，合法日期仍可读 |
| 时间计算得到负数 | 钳制为 0 并进入一次性自然完成流程，不显示负时间 |

## 15. 可访问性验收要点

- 页面语言正确声明为中文；
- 三个主要页面各有唯一明确主标题，视觉隐藏标题也应可被读屏识别；
- 当前快捷时长、滑块值、主题、声音和展开状态均有程序化状态；
- 圆环不能是剩余时间的唯一表达，中心必须有文本时间；
- 暂停状态同时有“已暂停”文字与“继续”按钮；
- 确认层具备模态语义、标题关联、焦点圈定和焦点归还；
- 图表提供逐日文本等价信息，不依靠柱高或颜色区分；
- 所有关键路径可只用键盘完成；
- 颜色对比度、正式焦点样式与最终字号在阶段 2 验证；
- 读屏不每秒播报倒计时，仅在开始、暂停、继续、完成和恢复时播报关键状态。

## 16. 易误触与歧义清单

1. 点击快捷值必须同步滑块，避免出现两个不同时间真值。
2. 滑块落在非快捷值时，不得保留旧快捷按钮选中态。
3. “再次冥想”使用原计划时长，不使用提前结束的实际时长。
4. 提前结束确认期间计时冻结；取消后是否恢复取决于进入确认前是进行还是暂停。
5. 暂停态的“继续”不得自动隐藏，空白点击也不能让页面只剩静止圆环而没有恢复入口。
6. 隐藏的控制不可响应点击，防止用户触碰看似空白区域却结束会话。
7. 自然完成与恢复结算竞争时必须只有一个获胜结果。
8. 完成页浏览器后退不能回到已结束且可再次操作的进行页。
9. 0 秒提前结束不写入完成记录；1 秒及以上按实际秒数记录。
10. 跨午夜完成按结算发生时的本地日期归档；同一会话只归入一个自然日。
11. 已暂停跨午夜仍在用户最终确认／自然完成所在日期归档，不拆分成两天。
12. 主题或声音偏好损坏不应破坏计时与记录。
13. 展开 15 天趋势不会改变页面主导航历史，不生成第四页。
14. 旋转屏幕、缩放和安全区变化只改变布局，不改变计时状态。
15. 页面恢复后不补播用户可能早已错过的完成音。
