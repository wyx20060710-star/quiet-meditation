# 2.1 自主优化记录

日期：2026-09-05。用户授权自主重新评估项目设计，并明确要求可回滚。

## 设计选择

原版已有可靠的计时、恢复、单次结算和本地存储基础。本次选择重组现有体验：桌面采用左侧安静文案、右侧准备卡片，手机按单列排列。时长选择、环境声和开始操作集中；记录从首页和完成页均可展开。

相比只做视觉微调，这一方案解决了记录难以访问、声音入口过深的问题；相比全面重写，保留经过测试的计时和存储基础更利于验证与回滚。本次没有增加依赖或数据迁移。

场景依旧跟随本地晨、昼、暮、夜变化。进行页保留倒计时圆环，提供键盘可达的显示操作按钮，控件自动淡出时保护键盘焦点。设置和结束确认使背景元素 inert，防止辅助技术或鼠标访问背景控件。

## 可靠性改动

- 运行中局部更新环境声勾选状态和文案，避免只更新计时造成声音显示过期。
- 时长输入排除非有限数值；活动会话不接受时长修改。
- 时长保存失败保留当前页选择并提示；开始失败停止环境声、恢复空闲场景调度并支持重试。
- 首页、完成页共享记录呈现与空状态。
- Vite 开发命令使用 runner 配置加载器，与测试和生产构建一致。
- Service Worker 缓存从 v8 升为 v9。
- 2.1.1 修订：开发环境只注销当前应用自身的 Service Worker，不清除缓存或影响同域其他应用。正式安装应使用 HTTPS 生产地址。
