# 极简冥想计时器：动效原型与交接规格

> 阶段：3 — 动效原型  
> 版本：1.0  
> 日期：2026-08-04  
> 上位约束：`PROJECT_CHARTER.md`、`docs/01-ux-spec.md`、`docs/02-visual-system.md`  
> 配套产物：`docs/03-motion-prototype.html`、`docs/03-motion-tokens.json`

## 1. 交付结论

阶段 3 已将阶段 2 的视觉边界转化为可交互原型，并冻结以下动效关系：

- 圆环呼吸周期采用 9 秒，缩放范围 `1 → 1.01 → 1`；只缩放环形图层，中央时间不缩放；
- 控制淡入 180 ms、淡出 240 ms，无操作 4 秒后隐藏；显隐不占文档流、不改变圆环位置；
- 页面进入 220 ms、退出 160 ms，最多 4 px 的低幅度纵向位移；新页面立即可交互，不等待离场结束；
- 提前结束确认层 180 ms 淡入并上移 4 px，退出 140 ms；打开瞬间冻结计时；
- 最近记录使用 240 ms 的高度揭示与淡入，无弹簧、反弹或横向位移；
- 减少动态效果模式取消呼吸、位移、进度补间和展开动画，只保留不超过 60 ms 的状态淡变或即时切换。

以上参数在两套主题、桌面与手机布局中共用。主题不拥有独立动画节奏。

## 2. 本阶段边界

原型用于验证动作语义、节奏、构图稳定性和减少动态效果，不是阶段 5 的 MVP。它有意不实现：

- 活动会话的刷新与关闭恢复；
- 15 天记录的真实本地持久化、清理和异常修复；
- 完成音播放、音频解锁和失败策略；
- PWA、离线缓存和安装；
- 系统时间跳变处理和生产级单次结算保护。

原型的计时显示使用真实时间差，足以验证暂停、继续、确认冻结和自然完成的动效衔接；生产状态模型与数据约定仍在阶段 4 固化。

## 3. 可交互原型说明

直接在浏览器打开 `03-motion-prototype.html`。核心验证路径：

1. 首页点击“开始冥想”，页面淡入进行页；
2. 点击圆环或空白区域，控制在 180 ms 内出现；
3. 等待 4 秒，控制淡出并退出命中与 Tab 顺序；
4. 再次唤出控制并暂停，圆环、进度和呼吸同步冻结，“继续”持续可见；
5. 打开“提前结束”，验证背景主体不位移、初始焦点落在“继续冥想”；
6. 取消后回到来源状态；确认后进入完成页；
7. 展开与收起最近记录，验证按钮焦点和文档顺序不变；
8. 切换两套主题，确认只改变语义色，不改变几何和节奏。

测试辅助参数只服务原型验证，不进入产品界面：

- `?demoSeconds=5`：把本次计划时长临时压缩为 5 秒，用于验证自然完成；
- `?motion=reduce`：在不修改系统设置时强制模拟减少动态效果；
- 两者可组合，例如 `03-motion-prototype.html?demoSeconds=5&motion=reduce`。

## 4. 动效变量

机器可读真值为 `03-motion-tokens.json`。CSS 或实现层应引用共享变量，不在组件内散落独立时长。

| 场景 | 进入 | 退出 | 缓动 | 位移／幅度 |
|---|---:|---:|---|---:|
| 页面 | 220 ms | 160 ms | `cubic-bezier(.2,0,0,1)` / `cubic-bezier(.4,0,1,1)` | 进入 4 px，退出 2 px |
| 进行页控制 | 180 ms | 240 ms | 标准／退出 | 0 px |
| 模态 | 180 ms | 140 ms | 标准／退出 | 4 px |
| 最近记录 | 240 ms | 240 ms | 标准 | 高度揭示，无平移 |
| 按钮按下 | 90 ms | 90 ms | 标准 | 向下 1 px |
| 圆环呼吸 | 9 s | 连续 | 标准对称 | `1 ↔ 1.01` |
| 减少动态淡变 | 0–60 ms | 0–60 ms | 线性或无 | 0 px |

动效优先级：状态立即成立，视觉过渡随后完成。点击“暂停”时先冻结计时真值，再播放状态淡变；页面导航时新页面立即获得交互能力，不使用动画制造等待。

## 5. 圆环呼吸与进度

### 5.1 图层分离

圆环由三个互不混用的图层组成：

1. 轨道：静态边界；
2. 进度：只表达剩余比例；
3. 中央时间与暂停文案：固定在主体坐标中，不参与呼吸缩放。

呼吸只作用于包含轨道和进度的 SVG 容器。最大 `scale(1.01)` 低于阶段 2 的 `1.012` 上限，360 px 圆环最大半径变化约 1.8 px，264 px 圆环约 1.3 px，不产生明显“脉冲”或计时提醒感。

### 5.2 运行、暂停与恢复

- 运行中：呼吸持续，进度按真实剩余比例更新；
- 暂停：呼吸使用 `animation-play-state: paused`，进度与时间保持冻结；
- 确认层：与暂停相同地冻结视觉和时间；
- 继续：从当前呼吸相位继续，不重新从最小值跳起；
- 后台恢复：阶段 5 实现时直接校正到真实进度，不播放追赶动画；
- 归零：停在 `00:00` 与空进度，再进入完成页。

进度补间可以使用 1 秒线性过渡来消除逐秒阶梯感，但不可成为计时真值。刷新、后台恢复或大幅校正时应临时取消补间并直接落位。

## 6. 控制显隐

### 6.1 显示

- 唤出触发：点击／轻触非按钮区域，或键盘用户按 `Tab`、`Space`；
- 视觉：180 ms 透明度变化，不缩放、不移动；
- 语义：显示开始时即移除 `inert` 并进入 Tab 顺序；
- 构图：控制使用固定覆盖层，圆环主体盒不参与重新布局。

### 6.2 自动隐藏

- 无操作时限固定为 4 秒；阶段 3 验证未发现缩短的必要；
- 指针、触控或键盘操作重置计时；
- 悬停控制或焦点在控制内时不隐藏；
- 淡出开始时设置不可命中并移出 Tab 顺序，视觉余晖不得形成幽灵按钮；
- `Escape` 可立即隐藏运行态控制；暂停态不能用空白或 `Escape` 隐藏“继续”。

淡出采用比淡入更慢的 240 ms，使控件离开不显突兀，但语义隐藏在淡出开始时立即生效，避免临界时刻误触。

## 7. 暂停与提前结束确认

暂停不做整体页面转场，只改变三个局部状态：时间冻结、呼吸冻结、“已暂停”淡入。按钮文案原位从“暂停”变为“继续”，控制持续可见。

确认层遵循以下顺序：

1. 在触发帧先冻结有效时长；
2. 显示遮罩并让面板在 180 ms 内淡入、上移最多 4 px；
3. 初始焦点进入“继续冥想”；
4. 取消时先恢复来源状态，再让确认层退出；
5. 从运行态取消会继续计时，从暂停态取消仍保持暂停。

遮罩不改变背景圆环的缩放、位置或线宽。确认层不使用弹簧动画，也不以红色闪现制造危险感。

## 8. 页面转场

页面只使用透明度与极小纵向位移。首页、进行页、完成页共享同一套参数：

- 进入：从 `opacity: 0; translateY(4px)` 到静止，220 ms；
- 退出：从静止到 `opacity: 0; translateY(-2px)`，160 ms；
- 进入层位于退出层下方但立即可交互；退出层立即停止命中；
- 不使用整页横向滑动，不暗示页面层级或浏览历史方向；
- 自然完成与提前结束使用相同页面转场，差异只由文案表达。

切换主题只过渡背景和文字色 220 ms，不做闪白、圆形扩散或布局变化。若切换主题时系统要求减少动态，颜色即时切换。

## 9. 最近记录展开

展开区紧随按钮进入文档流，使用 CSS grid 的 `0fr → 1fr` 高度揭示和透明度变化：

- 240 ms，标准缓动，无过冲；
- 展开按钮不位移到别处，焦点保持在按钮；
- `aria-expanded`、`aria-hidden` 与 `inert` 同步；
- 柱形只做一次 240 ms 的低幅度纵向显现，10 ms 错峰用于辨识数据序列，不形成庆祝波浪；
- 收起后内容立即移出焦点顺序，视觉收束继续完成。

生产实现若使用未知高度动画，应优先采用 CSS grid 或可中断的 Web Animations API；不得硬编码内容高度，避免 200% 文字缩放时截断。

## 10. 减少动态效果

系统媒体查询 `prefers-reduced-motion: reduce` 是正式入口，原型的 `?motion=reduce` 仅用于测试。减少动态模式下：

- 呼吸动画完全取消，圆环维持 `scale(1)`；
- 页面与控制不发生位移，状态直接切换或最多 60 ms 淡变；
- SVG 进度不做逐秒补间，直接显示当前比例；
- 模态不位移；
- 记录区直接展开／收起，柱形不依次生长；
- 自动隐藏仍为 4 秒；暂停、继续、确认、完成等状态语义完全不变。

减少动态不是“慢速动画”模式。实现不得通过延长时间来替代取消运动。

## 11. 响应式与性能约束

- 360 px 与 264 px 圆环共享周期和比例，不按尺寸改变速度；
- 低高度横屏将主体与控制左右排列，旋转和重排不改变计时状态；
- 动效只使用 `opacity` 和 `transform`；展开区的高度动画仅作用于小型次级内容；
- 不使用持续阴影、滤镜、Canvas 粒子或每帧 JavaScript 改写几何；
- 呼吸由 CSS 驱动；JavaScript 只更新倒计时文本和进度比例；
- 页面不可见时可暂停纯装饰性呼吸，但计时真值继续基于真实时间差；
- 200% 文字缩放允许纵向滚动，不压缩字号或延长动效。

## 12. 实现交接约定

阶段 5 应将动效层视为状态的消费者，而不是状态来源：

```text
计时／页面状态（真值）
          │
          ├── 可见内容与 ARIA 状态
          └── 动效呈现（可取消、可跳过）
```

任何转场被浏览器取消、页面切后台或用户切换减少动态后，状态都必须停在正确终点。不得用 `animationend` 才写入暂停、完成或结算结果；`animationend` 只允许清理临时 class。

需要共享的实现变量：

- `motion.duration.*`：进入、退出、呼吸和自动隐藏时长；
- `motion.easing.*`：标准、退出与线性缓动；
- `motion.distance.*`：页面、模态和按下位移；
- `motion.scale.*`：呼吸幅度。

## 13. 阶段 3 验收清单

### 13.1 圆环与计时理解

- [x] 呼吸缩放不超过 `1.012`，当前值为 `1.01`；
- [x] 中央时间字号和位置不参与呼吸；
- [x] 进度始终承担剩余比例，呼吸不表达训练指令；
- [x] 暂停和确认时进度、时间与呼吸同步冻结；

## 14. 进入阶段 4 的门槛

阶段 4 可在以下约束下开始：

1. 以 `03-motion-tokens.json` 为动效参数真值；
2. 以本文件的状态先行原则定义技术状态机，任何动画均不可承担业务真值；
3. 明确活动会话、真实时间差、暂停累计、一次性结算和恢复数据结构；
4. 为刷新、后台、关闭重开、系统时间变化与数据损坏制定可测试方案；
5. 保持原型验证通过的主体稳定性、4 秒控制时限和减少动态行为，不以框架限制为由改回布局动画。
