# 极简冥想计时器：阶段六体验增强记录

> 版本：0.6.1  
> 日期：2026-08-04  
> 状态：候选发布版本已实现并通过自动化与真实浏览器检查

## 1. 本阶段交付

- 接通自然矿石（默认）与柔和晨雾主题，偏好字段独立验证并持久化；
- 接通结束提示音偏好，自然完成最多由一个文档原子领取一次播放尝试；
- 声音不可用或播放失败时只更新回执状态，不阻断结算、统计或完成页；
- 完成运行中、暂停中、确认中、后台、锁屏等效、关闭重开、过期重开与完成页刷新恢复；
- 当前文档继续以单调时钟为真值，墙钟跳变检查点不会提前完成；
- 通过 `BroadcastChannel` 发送无载荷真值通知，接收页面始终重读 IndexedDB；
- 广播不可用或丢失时，页面在重新可见时主动重读并收敛；
- 加入 Web App Manifest、同源静态资源 Service Worker 缓存和应用图标；
- Service Worker 不读取 IndexedDB、不持有计时器、不驱动结算；
- 补齐确认弹层的初始焦点、Tab 圈定、Escape 取消、背景控制隐藏和焦点归还。
- 将进行页剩余时间圆环修正为从 12 点方向顺时针减少；
- 将自然完成音延长为 10 秒原创柔和五声音阶尾奏，使用长尾正弦音与极轻开放五度铺底；
- 音色方向参考 Mixkit 冥想分类中“Relaxation 05”的慢速、冥想、长笛与竖琴标签，但不复制或打包第三方曲目，以保持离线能力和清晰授权边界。
- 根据试听反馈将旋律与铺底的完成音增益统一提高约 30%，保留原淡入淡出包络。

## 2. 恢复矩阵结果

| 编号 | 场景 | 结果 |
|---|---|---|
| R01 | 运行中刷新、未到期 | 恢复同一会话，按墙钟检查点校正 |
| R02 | 暂停刷新 | 保持暂停且冻结累计值 |
| R03 | 确认层刷新 | 保持确认状态和 `resumeTo` |
| R04 | 后台／锁屏后未到期 | 隐藏前检查点，返回时重读校正 |
| R05 | 后台期间到期 | 幂等自然结算，统计只增加一次 |
| R06 | 关闭后未到期重开 | 恢复同一活动会话 |
| R07 | 关闭后过期重开 | 结算一次且不补播声音 |
| R08 | 同页墙钟前跳 | 检查点使用单调差，不提前完成 |
| R09 | 跨重开墙钟倒退 | 清除不可信活动会话，不写记录 |
| R10 | 恢复数据损坏 | 验证失败并回安全空状态 |
| R11 | 完成页刷新 | 只读现有回执，不重新结算或播放 |
| R12 | 完成页后退／返回 | 清除完成页引用并回首页 |

## 3. 验证结果

- Vitest：8 个测试文件、36 项断言通过；
- TypeScript：严格类型检查通过；
- Vite：生产构建通过，Manifest、Service Worker 和图标均进入 `dist/`；
- 浏览器：桌面和 360 × 720 视口无横向溢出；
- 浏览器：主题变量和浏览器主题色同步切换；
- 浏览器：运行、控制显隐、暂停、确认恢复、弹层焦点圈定和结束流程通过；
- 浏览器：控制台无错误或警告；
- HTTP：`manifest.webmanifest` 与 `sw.js` 均返回 200。

## 4. 增强层故障边界

- IndexedDB 打不开时使用当前文档内存仓库，核心流程仍可完成；
- BroadcastChannel 不可用时依赖可见性恢复重读；
- Web Audio 不可用时结算照常完成；
- Service Worker 注册、安装、更新或缓存失败时不改变普通网页流程；
- PWA 安装资格由实际浏览器和部署环境决定，不显示阻断式安装提示。
